家庭成员档案 · 用心记住

把生日、喜好、忌口、尺码一一记下，是"把对方家人请进生命"的第一步。

📦 数据保存方式有两种（互相兼容，可切换）：

方式 A · 云端跨设备同步（推荐）—— Supabase 云数据库：数据实时写入 PostgreSQL，切换浏览器 / 换电脑 / 手机端 都能立刻看到同一份数据。首次配置只需 3 步：

  1. 打开 supabase.com/dashboard → 新建项目 → 进入项目后：SQL Editor → 把仓库里 lovenest/data/supabase_init.sql 整段粘贴进去执行（如果此前已执行过一遍旧版本，请再执行文件最底部 🔧「补丁（PATCH）」段，用于放宽字段约束 + 升级旧称呼）。
  2. 同一项目左侧：Project Settings → API → 复制 Project URL 和 anon public（不是 service_role！）两个值。
  3. 在仓库中打开 lovenest/shared/supabase-config.js，将那两个值分别粘贴到 PROJECT_URL、ANON_PUBLIC_KEY 中，COUPLE_ID 保持默认即可（也可自定义成任意 UUID）。保存后重新打开页面，右上角徽标会从 💻 本机模式 变成 ☁️ 云端同步，即表示已生效。

方式 B · 本机手动同步（无需任何配置）：点击「⬇ 导出 JSON」把家庭数据下载成 family.json，换浏览器或换设备时再点「⬆ 导入 JSON」把这份文件导回来。刷新不丢失，但换浏览器前一定要先导出。

💡 两种方式共存：只要按方式 A 配好 Supabase，方式 B 会自动变成备份手段——不会覆盖云端数据。

把"待补充"一项项填满的过程，本身就是把两个家庭请进生命的过程。
