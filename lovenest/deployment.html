💻 当前：本机模式

☁️ 一键上云 · Supabase 部署向导

跟着 5 步走，不用改代码：新建成员 / 修改称呼，立刻在手机、另一台浏览器、任何设备同步。全程 3-5 分钟。

1

创建 Supabase 项目（免费版就够用；已有项目可直接跳到 Step 2）

打开 Supabase Dashboard → 🌏 Region 选新加坡 / 东京，国内访问延迟最低
点击上方按钮登录（GitHub / 邮箱都行）→ New Project → 名字随意（比如 love-nest）→ 密码随便填一个记下来（不会再用到）→ Region 选 ap-southeast-1 (Singapore) 或 ap-northeast-1 (Tokyo) → 点击 Create project，等待 1-2 分钟初始化完成。
2

初始化数据库（把家族、银行、里程碑等所有表一次性建好）整个项目只需要跑 1 次

打开 Supabase SQL Editor →
② 点右边 「打开 Supabase SQL Editor」 → 选你刚建的项目 → 点 New query → 粘贴刚才复制的 SQL → 点击左下角 ▶ Run。
成功后会显示："Success. No rows returned"（底部有验证语句可以单独跑一遍，看计数是否匹配）。
⚠️ 如果 Step 2 执行时报「约束/字段类型错误」：说明你之前已经建过旧表，请 再点击一次「只复制补丁段」，在同一个 SQL Editor 新建一个 query，单独粘贴补丁段并 Run。
3

连接到你的项目（粘贴 2 个值，本向导立刻帮你验证）无需改任何代码文件，配置会存在浏览器里

在 Supabase Dashboard 里：左侧菜单最底部 Project Settings ⚙️ → API，复制下面 2 项粘贴到表单：
  • Project URL（长得像 https://xxxx.supabase.co）
  • anon public（长 JWT 字符串，开头是 eyJhbGc...）—— ⚠️ 千万别选 service_role！那个权限太大只能服务器用。
未连接
4

把你本机浏览器里已经填好的数据同步到云端（之前在本机加的成员、改的称呼、银行流水都会一次上传）

✅ 已连接到云端！现在点下面的按钮，把本机浏览器里的所有数据（家族成员 / 银行流水 / 里程碑 / 冲突复盘……）全部一次性 Upsert 到你的 Supabase 数据库。
5

完成 ✅ · 立刻去家族树验证一下跨浏览器同步

🎉 恭喜，已经全部搞定！

现在家族树的任何新增成员、修改称呼、勾选节日，都会实时同步到云端。换台电脑/换浏览器只要走一遍 Step 3 粘贴同一个 URL + anon key，立刻看到同一份数据。

打开家族树页面验证 →
💡 建议顺手 下载 1 份 JSON 备份（家族树页面 → 工具栏 → ⬇ 导出 JSON），作为离线双保险。
